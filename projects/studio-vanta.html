Identidad & sitio web

Una identidad para un estudio que las hace.

Studio Vanta es un estudio de diseño basado en Buenos Aires que pidió una identidad capaz de sostener un trabajo editorial sin caer en los clichés visuales del rubro. El proyecto cubrió la marca, el sistema visual y el sitio web — todo bajo una misma lógica: menos elementos, más intención.

Restricción como método.

Una sola familia tipográfica, una paleta reducida a blanco y negro, y rojo como único acento. La grilla del sitio se construyó en HTML puro — sin frameworks, sin CMS, sin dependencias.

La marca opera como sello: funciona en negro sobre blanco y en blanco sobre rojo profundo. El logotipo prescinde de ornamentos.

Editorial antes que UX.

El sitio se estructura como una grilla editorial: hero, índice de proyectos, ficha técnica. Cada bloque respira por sí solo. La navegación es lineal — sin menús desplegables, sin sidebars.

Imágenes a sangrado, sin marcos. Display para títulos, sans para cuerpo, mono para metadata.

Un sistema que se mantiene solo.

El cliente actualiza el sitio sin pedir ayuda. Las plantillas son archivos planos. La marca se reconoce a la distancia sin necesidad de gritar. Todo el sistema cabe en menos de mil líneas de código.
